EXPLICACIÓN BREVE:

Este proyecto es una página web básica creada con HTML5, CSS3 (Bootstrap) y JavaScript.

El objetivo fue practicar los 7 fundamentos de JavaScript:
1. Variables y tipos de datos
2. Arreglos y objetos
3. Condicionales IF/ELSE
4. Bucles (for, while, do...while)
5. Funciones
6. Alcance (Scope)
7. Clausuras (Closures)

La página incluye un botón interactivo que ejecuta una función y muestra el resultado en pantalla. Todos los ejercicios se imprimen en la consola del navegador (Click derecho > Inspeccionar > Consola).

Archivos incluidos:

- index.html (con comentarios de HTML5)
- style.css
- script.js
